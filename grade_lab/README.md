# 성적 분석실 (고1·2 · 가상 자료)

AI 없이 계산만 하는 첫 단계다. 학생과 점수는 모두 가상이다.

## 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `generate_sample.py` | 가상 학생 100명(고1 영어, 4개 반)의 성적 CSV와 `rules.json`을 만든다 |
| `analysis.py` | 시험별 요약, 학생별 변화, 전국연합 문항 분석 (AI 사용 안 함) |
| `naesin.py` | 학기 성적(원점수·성취도·분포비율·5등급 석차등급) |
| `simulate.py` | 중간고사 뒤 기말 시뮬레이션 (필요한 기말 점수) |
| `student_sheet.py` | 학생용 한 장 (`output/students/<학생>.html`). 본인 점수와 공개 통계만 담음 |
| `report.py` | 결과를 `output/report.html` 한 장으로 만든다 (인터넷 없이 열림) |
| `tests/` | 계산 검증 (손계산 자료 + 표준 통계 모듈 + 하나씩 다 따져 보는 느린 계산과 대조) |
| `data/sample/` | 가상 자료 CSV (엑셀에서 열 수 있음). 문항 자료 `items.csv`·`responses.csv`, 수행평가 `performance.csv`, 학교 규칙 `rules.json` 포함 |

## 가상 시험 구성

오늘이 2학기 중간고사가 끝난 뒤라고 가정한다.

| 시험 | 종류 | 들어 있는 항목 |
|---|---|---|
| 3·6·9월 전국연합 | 전국연합(교육청) | 원점수, 등급, 문항별 정오 |
| 1학기 중간·기말고사 | 내신(지필) | 원점수 |
| 1학기 수행평가 | 내신(수행) | 40점 만점 점수 (`performance.csv`) |
| 2학기 중간고사 | 내신(지필) | 원점수 → 기말 시뮬레이션에 사용 |

전국연합 원점수는 맞힌 문항 배점의 합으로 만든다(3점 10문항 + 2점 35문항 = 100점). 문항 유형 배치는 가상 값이다.
고3(9등급, 평가원)은 다루지 않는다. 평가원 자료 처리 기능은 코드에 남아 있다.

일부러 넣은 예외: 결시(S007 1학기 중간, S019 6월, S023 9월, S052 2학기 중간), 수행 결시(S088 1학기), 누락(S011 3월 등급 칸 빈칸).

## 학교 규칙 (`rules.json`)

학교·교과마다 다른 규칙은 코드에 넣지 않고 `rules.json`에 둔다. `status`가 `가정`이면 화면에 ‘가정’으로 표시된다.
학교 학업성적관리규정을 확인하면 값을 고치고 `status`를 `확인됨`으로 바꾼다.

기본값은 [광주광역시교육청 2025학년도 고등학교 학업성적관리 시행지침](https://www.gen.go.kr/flexer/html/www/356/2025/20250320_151807_067017800.files/Sections1.html)을 따른다.
상태: `확인됨`(학교 규정까지) / `교육청 지침`(지침에서 확인, 학교 규정은 아직) / `가정`(확인 못 함).

| 항목 | 지금 값 | 상태 |
|---|---|---|
| 석차등급 비율 | 누적 10 / 34 / 66 / 90 / 100 % | 교육청 지침 |
| 등급 경계 | 누적 인원 = 수강자 수 × 누적 비율 반올림. 동점자가 경계에 걸치면 중간석차 백분율 | 교육청 지침 |
| 반올림 | 환산 합계 소수 둘째 자리 → 원점수 정수 (0.5는 올림), 과목평균 소수 첫째 자리 | 교육청 지침 |
| 성취도 기준 | 고정분할 A 90 / B 80 / C 70 / D 60, 40 미만은 최소 성취수준 보장지도 | 교육청 지침 |
| 석차를 매기는 점수 | 원점수(정수) | 가정 |
| 반영 비율 | 중간 30 / 기말 30 / 수행 40 (교과협의회 → 학업성적관리위원회 심의 → 학교장 결정) | 가정 |

규칙에 따라 같은 점수라도 등급이 달라질 수 있다(테스트 `test_rule_choice_changes_result`에 예시).

## 기말 시뮬레이션

- **성취도**: 내 점수만으로 정해지므로 필요한 기말 점수를 정확히 계산한다.
- **석차등급**: 다른 학생 점수에 따라 달라지므로 단정하지 않는다. 다른 학생 기말 점수를 1학기 ‘중간→기말’ 흐름(직선 + 흔들림)으로 400번 만들어 보고,
  목표 등급이 50%(반반)·80%(안정권)에서 나오는 기말 점수를 보여 준다. 시나리오: 1학기 흐름 그대로 / 평균 5점 낮게 / 5점 높게.
- **수행평가**는 보통 기말 뒤에 하므로 예상 점수(1학기와 같은 비율, 100·90·80·70%)를 골라 본다. 다른 학생 수행은 각자 1학기 비율로 가정한다.
- 공부 시간은 자료로 알 수 없어 ‘중간 대비 몇 점’으로만 보여 준다.
- `report.html`은 교사용이다. 파일 안에 모든 학생 점수가 들어 있으므로 학생에게 그대로 주지 않는다.

## 학생용 한 장

`python grade_lab\report.py`를 실행하면 `output\students\` 아래에 학생마다 HTML 파일이 하나씩 생긴다(교사 화면의 ‘학생용 한 장 열기’ 링크).

- 들어가는 것: 본인 점수, 성적표에 원래 나오는 통계(과목평균·분포비율·수강자수), 본인의 필요한 기말 점수, 전국연합에서 틀린 쉬운 문항.
- 들어가지 않는 것: 다른 학생의 번호·이름·점수, 석차. 테스트(`test_student_sheet.py`)로 확인한다.
- 학생이 목표를 고르고 계획을 적는다. 적은 내용은 그 컴퓨터의 브라우저에만 저장되고 어디로도 보내지 않는다.
- A4 양면 한 장으로 인쇄된다(앞: 내 위치·필요한 점수, 뒤: 목표·계획·다시 볼 문항).

## 계산 원칙

- 내신과 모의고사는 합산하거나 한 선으로 잇지 않는다.
- 결시는 통계에서 빼고 따로 센다. 응시했는데 필요한 칸이 비면 '누락'으로 센다.
- 표준편차는 모집단 표준편차(n으로 나눔).
- 등급은 순서 값이므로 평균 대신 분포와 중앙값으로 보여 준다.
- 변화는 바로 앞 시험과 비교하고, 값이 없으면 '비교 불가(이유)'로 적는다.
- 지필·수행 결시 학생은 학교 규정의 인정점이 없으면 학기 성적과 시뮬레이션에서 빼고, 이유를 화면에 적는다.
- 반올림은 사사오입(0.5는 올림). 파이썬 기본 `round()`는 쓰지 않는다.
- 문항 정답률 구간: A 80~100%(가장 쉬움), B 60~80, C 40~60, D 20~40, E 0~20. 경계값은 위쪽 구간에 넣는다(80%는 A).
- 우리 반 정답률이 들어가는 구간을 전국 구간과 비교해 '높음/범위 안/낮음'으로 표시한다.
- 자료 점검: 원점수가 맞힌 문항 배점의 합과 다르면 화면에 '확인 필요'로 띄운다.
