# 성적 분석실 (첫 버전 · 가상 자료)

AI 없이 계산만 하는 첫 단계다. 학생과 점수는 모두 가상이다.

## 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `generate_sample.py` | 가상 학생 30명(고3 영어)의 성적 CSV를 만든다 |
| `analysis.py` | 시험별 요약, 학생별 변화 계산 (AI 사용 안 함) |
| `report.py` | 결과를 `output/report.html` 한 장으로 만든다 (인터넷 없이 열림) |
| `tests/test_analysis.py` | 계산 검증 (손계산 자료 + 표준 통계 모듈 대조) |
| `data/sample/` | 가상 자료 CSV (엑셀에서 열 수 있음). 전국연합 문항 자료 `items.csv`(45문항 배점·유형·전국 정답률 구간), `responses.csv`(학생별 정오) 포함 |

## 가상 시험 구성

| 시험 | 종류 | 들어 있는 항목 |
|---|---|---|
| 3월 전국연합 | 전국연합(교육청) | 원점수, 등급 |
| 1학기 중간고사 | 내신 | 원점수 |
| 6월 모의평가 | 평가원 | 등급만 (원점수 없음) |
| 1학기 기말고사 | 내신 | 원점수 |
| 7월 전국연합 | 전국연합(교육청) | 원점수, 등급 |

전국연합 원점수는 맞힌 문항 배점의 합으로 만든다(3점 10문항 + 2점 35문항 = 100점). 문항 유형 배치는 가상 값이다.

일부러 넣은 예외: 결시 4건(S07 중간, S19 6월, S23 기말·7월), 누락 1건(S11 3월 등급 칸 빈칸).

## 윈도우 PC에서 실행하기

Python 3.12 이상이면 추가 설치 없이 돌아간다. 프로젝트 폴더가 `C:\ai-lab\lmstudio`라고 할 때:

```powershell
cd C:\ai-lab\lmstudio
python grade_lab\report.py
start grade_lab\output\report.html
```

계산 검증:

```powershell
python -m unittest discover -s grade_lab\tests -v
```

## 계산 원칙

- 내신과 모의고사는 합산하거나 한 선으로 잇지 않는다.
- 결시는 통계에서 빼고 따로 센다. 응시했는데 필요한 칸이 비면 '누락'으로 센다.
- 표준편차는 모집단 표준편차(n으로 나눔).
- 등급은 순서 값이므로 평균 대신 분포와 중앙값으로 보여 준다.
- 변화는 바로 앞 시험과 비교하고, 값이 없으면 '비교 불가(이유)'로 적는다.
- 문항 정답률 구간: A 80~100%(가장 쉬움), B 60~80, C 40~60, D 20~40, E 0~20. 경계값은 위쪽 구간에 넣는다(80%는 A).
- 우리 반 정답률이 들어가는 구간을 전국 구간과 비교해 '높음/범위 안/낮음'으로 표시한다.
- 자료 점검: 원점수가 맞힌 문항 배점의 합과 다르면 화면에 '확인 필요'로 띄운다.
